This is a learning design for a system like the one named. It is not a description of any company’s internal architecture.

What you’ll learn

  • Fan-out via queues, per-channel workers
  • User preferences, rate limits, dedup, retries
  • Priority (OTP vs marketing)

The story behind it

An OTP must arrive in 5 seconds; a 'Diwali sale' push can go to 10 crore users over an hour. Same system, different priorities.
