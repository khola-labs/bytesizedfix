This is a learning design for a system like the one named. It is not a description of any company’s internal architecture.

What you’ll learn

  • Partitioning with consistent hashing; replication with quorums
  • Failure detection, hinted handoff, anti-entropy (intuition)
  • Eviction for caches

The story behind it

A city-wide network of lockers where any locker can store your bag and you can always get it back even if one locker room floods.
