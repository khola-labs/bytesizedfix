This is a learning design for a system like the one named. It is not a description of any company’s internal architecture.

What you’ll learn

  • High-frequency location ingestion
  • Geospatial indexing: geohash / quadtree / H3
  • Matching, surge, trip state machine

The story behind it

Raining in Bengaluru at 6 pm, 50 autos within 2 km sending GPS every 4 seconds, 5,000 people booking — who gets matched with whom?

Before this lesson

  • Real-time communication: polling, long polling, WebSockets, SSE (System Design L5)
  • Partitioning/sharding: range, hash, hot shards, resharding (System Design L16)
  • Search: inverted indexes, ranking, Elasticsearch (System Design L28)
