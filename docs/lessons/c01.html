Design a URL shortener

This is a learning design for a system like the one named. It is not a description of any company’s internal architecture.

What you’ll learn

  • Full interview flow on the simplest system
  • ID generation: counter + base62 vs hashing; collisions
  • Read-heavy caching, redirects (301 vs 302), analytics

The story behind it

Long Aadhaar-style application URLs shared in a family WhatsApp group get turned into short links; a crore people click the same link at once after a viral forward.
