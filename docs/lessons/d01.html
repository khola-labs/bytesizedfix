What you’ll learn

  • Count operations instead of seconds
  • Recognise O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ) from code shape
  • Use constraints (n ≤ 10⁵ etc.) to pick a target complexity

The story behind it

Chai for a shaadi with 500 guests: boiling one big patila takes the same effort for 5 or 500 guests (O(1)); pouring cup by cup grows with guests (O(n)); every guest clinking glasses with every other guest explodes (O(n²)); the halwai finding one guest by halving the alphabetical seating list needs ~9 looks (O(log n)).
